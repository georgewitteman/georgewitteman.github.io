DNS lookup

Looks up a name's DNS records with a DNS-over-HTTPS server. Enter an IP address to look up its reverse DNS name.

Notes
  • DNS has no way to ask for every record at a name, so this checks each common record type one by one. Some records live on special names, like _dmarc.example.com or _443._tcp.example.com.
  • TTL (time to live) is how long the server will keep using its cached copy of a record. It counts down, so it changes between lookups.
  • Any DNS-over-HTTPS server works, as long as it allows requests from web pages (CORS). The server is kept in the page address, so links and bookmarks keep it too.
  • When a signed domain's DNSSEC is broken, the server refuses to answer. The page then asks again with validation turned off and shows that answer with a warning.
  • WHOIS links for IP addresses go to Hurricane Electric's BGP Toolkit.
