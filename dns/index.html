DNS lookup

Looks up a name's DNS records with both Google Public DNS and Cloudflare (1.1.1.1), and shows where their answers differ. Enter an IP address to look up its reverse DNS name.

Notes
  • DNS has no way to ask for every record at a name, so this checks each common record type one by one. Some records live on special names, like _dmarc.example.com or _443._tcp.example.com.
  • TTL (time to live) is how long the resolver will keep using its cached copy of a record. It counts down, so it often differs a little between Google and Cloudflare.
  • Answers can differ between the two for names behind CDNs or load balancers, which hand out different addresses depending on who asks.
  • WHOIS links for IP addresses go to Hurricane Electric's BGP Toolkit.
